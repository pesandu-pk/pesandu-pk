### Things I've built

**[Altrium Recruitment Tracker](https://github.com/pesandu-pk/altrium-recruitment)** – recruitment app with CV scoring, interview scheduling and a Gemini chatbot. React + Supabase, hosted on Vercel. You can try it [here](https://altrium-recruitment.vercel.app/).

**[Hotel Booking ML Analysis](https://github.com/pesandu-pk/hotel-booking-ml-analysis)** – predicting booking cancellations, forecasting revenue and grouping customers, using about 119k hotel bookings. Random Forest did best at ~90% accuracy.

**[Admissions Chatbot](https://github.com/pesandu-pk/admissions-chatbot)** – my first chatbot, for answering uni admissions questions. Rule-based, with some basic NLP using NLTK.

**[Smart Fitness Database](https://github.com/pesandu-pk/smart-fitness-database)** – a MySQL database for a gym, normalised to 3NF, with separate access for trainers and members.

**[C++ Phone Book](https://github.com/pesandu-pk/cpp-phone-book)** – first-year project where I learned OOP properly.

And going way back – [Cinephile Critics](https://cb015766.wixsite.com/cinephile-critics), a movie review site I made on Wix in my foundation year.
